# 담당과 공유 규칙

11주차 협의 결과와 전체 담당 범위는 [역할 분담 및 합의](../역할분담.md)를 기준으로 합니다.

| 담당 | 소유 영역 | 이번 베이스 코드 상태 |
|---|---|---|
| A | 서버 실행, 소켓 연결, 로그인, 접속자 목록, 공통 통신 | 구현 및 예외·전송·종료 보완. 실제 TCP 검증 대기 |
| B | 방 생성·참여·퇴장, 채팅, 공지, 메시지 관리 | RoomManager 연결 지점 준비 |
| C | 미니게임 3종, 개인 최고 기록, 코인 지급·잔액, 이모티콘 구매·관리·전송 | GameService 연결 지점 준비 |

이모티콘 전송은 C가 담당하며 마지막 개발 주인 15주차에 공동 검토하면서 통합한다는 팀 합의를 따릅니다. 구체적인 게임·코인 내부 클래스 분리는 해당 담당자가 설계안의 CoinService, EmoticonService 등을 활용하여 확장합니다.

A는 ClientHandler의 switch와 공통 파서를 관리합니다. B·C는 자기 담당 클래스에 기능을 작성합니다. 명령어를 추가할 때 담당 메서드 서명을 먼저 공유하고 A가 switch에 한 줄 호출을 추가합니다. 공통 파일을 각자 수정해 서로 덮어쓰지 않습니다.

수업 다중 클라이언트 코드를 기준으로 확장하고, 이용할 수 없는 코드는 새로 작성합니다. 현재 베이스 코드는 수업 원본이 제공되지 않아 Java 표준 소켓으로 새로 작성한 상태입니다.

공유는 GitHub와 카카오톡 ZIP을 함께 사용한다는 합의를 따릅니다. GitHub에는 src, docs, README.md, AGENTS.md, 역할분담.md, run.sh, run.ps1, .gitignore를 올리고 build와 dist는 제외합니다. ZIP에는 같은 소스와 실행 방법, 역할·통신 문서를 넣습니다. 업로드 전 일반 터미널에서 통합 테스트를 실행하고 ZIP의 내용과 GitHub 소스 버전을 맞춥니다.

공유 저장소: https://github.com/NETPG4/spvmroqkf
